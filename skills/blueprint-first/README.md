
`superpowers:brainstorming` not only automates actual coding tasks, but may also, at times, automate human thought processes. `blueprint-first` serves as an alternative to `superpowers:brainstorming`; it is a mechanism designed to prevent the automation of human thought by having humans write their own specifications. An AI agent using this skill will answer questions about the specifications of the current code, but it will not make any suggestions.

## Requirements

This skill expects the following Superpowers skills to be available:

- `superpowers:using-git-worktrees`
- `superpowers:writing-plans`
